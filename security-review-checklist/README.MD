# Bitcoin Product Security & Production Readiness Checklist

A practical checklist for engineering teams preparing Bitcoin products for production.

## What it covers

- Scope definition
- Key management & wallet architecture
- Transaction & payment flows
- Node & infrastructure security
- Backend & API security
- Operational security
- Risk classification

## Use it to

- Identify production risks
- Structure an internal security review
- Prepare for a production launch
- Identify areas requiring deeper engineering review

## Important

This checklist is a starting point for engineering review.  
It does not replace a full security assessment, code review, penetration test, or production readiness review.
